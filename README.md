# צוות המגדלור: משחק ללימוד אותיות

משחק דו-ממדי בסגנון של סדרה מצוירת, לגילאי 3 עד 6. צוות של שישה כלבלבי חילוץ וקפטן אורי מהמגדלור מצילים אותיות במפרץ. גרסה 1.1 מלמדת את 22 האותיות ואת 5 האותיות הסופיות, ב-8 תחנות.

- **ציורים:** נוצרו עם מודל התמונות gpt-image-2.5 של OpenAI (`tools/images.py`, ההוראות ב-`art/prompts.json`), ונחתכו לדמויות בודדות (`tools/sprites.py`).
- **קריינות:** קולות טבעיים של OpenAI (gpt-4o-mini-tts). ballad לקפטן, וקול אחר לכל כלבלב. יש הנחיות הגייה לשמות האותיות (`audio/pronunciation.txt`).
- **משחקים:** בכל תחנה שני מיני-משחקים שונים: מציאת אות, תפיסה, זיכרון, מיון בגרירה, וצביעה באצבע. בביקור חוזר המשחקים מתחלפים.

המשחק הוא אתר סטטי: HTML, CSS ו-JavaScript, בלי ספריות.

## הרצה במחשב

1. פותחים טרמינל בתיקיית הפרויקט.
2. מריצים שרת מקומי:

```bash
python -m http.server 8765
```

3. פותחים בדפדפן את הכתובת `http://localhost:8765`.

אפשרויות לבדיקה (לא לילדים):

- `?scene=map&profile=<id>` פותח ישר מסך מסוים.
- `?fast` מקצר את זמני ההמתנה כשאין קול עברי. שימושי לבדיקות אוטומטיות.
- `dev/review.html` מנגן את כל משפטי הקריינות, עם תמלול לבדיקה.

## העלאה ל-GitHub Pages והתקנה בטאבלט

1. מריצים את `node tools/build.mjs`. הפקודה מעדכנת את רשימת הקבצים לעבודה בלי אינטרנט.
2. מעלים את כל התיקייה למאגר ב-GitHub.
3. במאגר: Settings, Pages, בוחרים את הענף הראשי ואת התיקייה `/ (root)`.
4. בטאבלט, ב-Chrome, פותחים את הכתובת של האתר.
5. בתפריט של Chrome בוחרים "הוספה למסך הבית" או "התקנת אפליקציה".
6. פותחים את המשחק פעם אחת כשיש אינטרנט. מאותו רגע המשחק עובד גם בלי אינטרנט.

הערה: בתוכנית החינמית של GitHub, אתר Pages צריך מאגר ציבורי.

## קריינות

הקריינות עובדת בשלוש רמות, לפי הסדר:

1. הקלטה שלכם: `audio/custom/<מזהה>.mp3`.
2. קובץ קול ממוחשב: `audio/tts/<מזהה>.mp3`.
3. מנוע הדיבור של המכשיר, בעברית.

כל המשפטים והמזהים שלהם נמצאים בקובץ `audio/lines.txt`. דוגמה: המזהה `find.mem` הוא המשפט "אֵיפֹה הָאוֹת מֵם?".

אחרי שמוסיפים קבצי קול, מריצים שוב `node tools/build.mjs` ומעלים מחדש.

### קול עברי בטאבלט אנדרואיד

בלי קבצי קול, המשחק משתמש בקול של המכשיר. כדי שיהיה קול עברי:

1. פותחים את ההגדרות של הטאבלט.
2. עוברים אל ניהול כללי, שפה, המרת טקסט לדיבור (השמות משתנים בין מכשירים).
3. בוחרים במנוע של Google.
4. מורידים את חבילת הקול לעברית.

במסך ההורים יש כפתור "בדיקת קול", והוא מראה אם נמצא קול עברי.

### הקולות

קבצי הקול בתיקייה `audio/tts` כבר נוצרו. ההגדרות של כל דובר (הקפטן וכל כלבלב) נמצאות ב-`audio/voices.json`.

כדי ליצור קבצים מחדש (למשל אחרי שינוי טקסט), מגדירים את המפתח `OPENAI_API_KEY` ומריצים:

```bash
python tools/tts.py --check
```

- הכלי יוצר רק קבצים חסרים, או קבצים שהטקסט או הקול שלהם השתנו.
- הכלי בודק את האורך של כל קובץ. אם הקול הוסיף מילים או נקטע, הכלי יוצר את הקובץ שוב.
- `--check` מתמלל את המשפטים הארוכים, ויוצר שוב משפט שהמילים שלו לא תואמות.
- הערכת העלות של כל הרצה נרשמת ב-`dev/openai-cost.json`. כל 264 המשפטים עולים בערך 30 סנט.

### ציורים

```bash
python tools/images.py
```

```bash
python tools/sprites.py
```

הפקודה הראשונה יוצרת תמונות חסרות לפי `art/prompts.json`. הפקודה השנייה חותכת את גיליונות הדמויות וממירה הכול ל-WebP. כל תמונה עולה בערך 2 עד 3 סנט.

## מסך ההורים

לוחצים על כפתור גלגל השיניים (בפינה השמאלית התחתונה) ומחזיקים 3 שניות. אחר כך עונים על תרגיל חשבון. במסך:

- שם, גיל ותחנת פתיחה לכל ילד.
- מצב כל אות: חדשה, בלמידה, או ידועה.
- הטעויות הנפוצות: איזו אות ביקשנו, ובאיזו אות הילד נגע.
- מהירות דיבור, הצגת טקסט של הקריינות, צלילים.
- גיבוי ההתקדמות לקובץ, וטעינה מקובץ.

ההתקדמות נשמרת רק בטאבלט (localStorage). אם מוחקים את נתוני הדפדפן, ההתקדמות נמחקת. לכן כדאי לשמור גיבוי.
